Estruturas de Dados

Tipos Lineares
Arrays (Vetores)
Acesso: O(1). Definição: Coleção de elementos adjacentes na memória. Ideal para listas de tamanho fixo onde a leitura rápida é prioridade.
Listas Ligadas
Inserção: Rápida (apenas muda ponteiros). Definição: Cada elemento (nó) conhece o próximo. Ótima para alocação dinâmica de memória.
Pilhas (LIFO)
LIFO: Last-In, First-Out. Uso: Desfazer ações (Ctrl+Z), histórico de navegação e chamadas de funções recursivas.
Filas (FIFO)
FIFO: First-In, First-Out. Uso: Escalonamento de processos, filas de impressão e buffers de transmissão de dados.
Tipos Não Lineares
Árvores (Trees)
Hierarquia: Estruturas como Binary Search Trees organizam dados para buscas rápidas. Usadas em sistemas de arquivos e índices de bancos de dados SQL.
Grafos
Conexões: Conjunto de vértices e arestas. Essenciais para representar redes sociais, mapas (Google Maps) e sistemas de recomendação.
Hash Tables (Mapas)
Velocidade: Busca, inserção e remoção tendem a O(1). Associa uma chave a um valor através de uma função hash. Base de dicionários em Python e objetos JSON.

Conceitos de Big Data

Os 5 Vs Fundamentais
Volume & Velocidade
Volume: Petabytes de dados gerados diariamente. Velocidade: Necessidade de análise em frações de segundo (fraudes bancárias).
Variedade & Veracidade
Variedade: Dados estruturados (SQL), semi (JSON) e não estruturados (Vídeos). Veracidade: Limpeza de ruídos e dados falsos.
Valor
O Objetivo Final: Transformar dados brutos em inteligência de negócio e lucro. Sem valor, o Big Data é apenas um custo de armazenamento.
Arquiteturas de Processamento
Processamento em Batch (Lote)
Grandes volumes processados de uma vez (ex: Hadoop MapReduce). Geralmente executado em janelas de tempo (ex: toda madrugada).
Streaming (Tempo Real)
Dados processados instantaneamente conforme chegam (ex: Apache Flink, Spark Streaming). Crucial para monitoramento e IOT.
Arquitetura Lambda
O "Melhor dos dois mundos": Mantém uma camada de Batch para precisão histórica e uma camada Speed para resultados imediatos.
